# One Style — الموقع الحقيقي (Cloudflare)

هذا المستودع الخاص فيه كود الموقع كامل: الواجهة نفسها اللي بالمعاينة، والسيرفر (Cloudflare Worker) مع قاعدة البيانات، والاختبارات. خطوات التشغيل على حساب المحل موجودة بـ **`Cloudflare-guide.md`**.

## شو بيعمل

- تعديلات صاحب المحل من اللوحة (الأجهزة، الأسعار، الصور، النصوص، التوصيل) بتنحفظ على السيرفر وبيشوفها كل الزوار.
- الطلبات بتوصل للوحة برقم `OS-1001` وما بعده، والسعر بيحسبه السيرفر من الأسعار المنشورة.
- **حسابات الزبائن:** تسجيل، دخول، بياناتي، تغيير كلمة السر، وطلباتي مع حالتها. الطلب كضيف كمان متاح.
- **«نسيت كلمة السر» بالإيميل** للزبائن وللوحة. مخفي لحد ما ينضاف الدومين وResend.
- لكل جهاز صفحة بعنوان حقيقي، بالإنجليزي على `/devices/<اسم>` وبالعربي على `/ar/devices/<اسم>`، مع `sitemap.xml` لـ Google.
- **الطلب من الموقع متوقف** لحد ما يشغّله صاحب المحل من اللوحة. قبلها زر الطلب بيفتح واتساب، والموقع مخفي عن Google.

## الملفات

| المسار | شو فيه |
|---|---|
| `index.html`, `app.js`, `admin.js`, `data.js`, `settings.js`, `*.css`, `assets/` | الواجهة نفسها اللي بمعاينة GitHub Pages. لما تنفتح لحالها من الجهاز بتشتغل كمعاينة بدون سيرفر. |
| `live.js`, `live.css` | بيحوّلوا الواجهة لموقع حقيقي: المحتوى من السيرفر، الطلب، الحسابات، العناوين الحقيقية، دخول اللوحة. بينضافوا بس بنسخة Cloudflare. |
| `worker/src/` | السيرفر: `index.js` (التوجيه)، `orders.js`، `customer.js` (حسابات الزبائن)، `admin.js` (اللوحة)، `content.js`، `pages.js` (صفحات Google)، `mail.js` و`reset.js` (الإيميل). |
| `migrations/` | جداول قاعدة البيانات D1. أي تغيير على الجداول بيكون بملف جديد (`0002_…sql`)، مش بتعديل القديم. |
| `wrangler.jsonc` | إعدادات Cloudflare. الأرقام `REPLACE_WITH_…` بتنحط من الدليل، والأسرار ما بتنكتب هون أبداً. |
| `tools/build.mjs` | بيبني `dist/` (اللي بينشر)، وبيعمل للسيرفر نسخة من قواعد المتجر من `data.js` و`settings.js`. |
| `tests/` | الاختبارات (تحت). |
| `Cloudflare-guide.md` | دليل التشغيل خطوة بخطوة. |

**قاعدة مهمة:** الأسعار وخيارات الذاكرة والتخزين ورسوم التوصيل محسوبة بنفس الدوال بـ `settings.js` للمتصفح وللسيرفر. أي تعديل عليها بيوصل للثنين بعد `npm run build`.

## التشغيل على جهازك

بده Node.js 22 أو أحدث.

```sh
npm ci
npm run db:local       # مرة أولى: جداول قاعدة بيانات محلية
npm run dev            # http://127.0.0.1:8788 بقيم تجريبية من tests/local/test.env
```

- رمز الإعداد المحلي هو `test-setup-code-1234567890`.
- الإيميلات محلياً بتروح على بديل محلي، مش لإيميل حقيقي.
- المعاينة بدون سيرفر: افتح `index.html` مباشرة من المجلد.

## الاختبارات

```sh
npm test               # فحوصات سريعة بدون سيرفر: الأسعار، العناوين، تنظيف المحتوى
npm run test:api       # 125 فحص على الطلبات واللوحة (بده python3)
npm run test:accounts  # 57 فحص على حسابات الزبائن وروابط كلمة السر
npm run test:browser   # الموقع كامل بمتصفح (بده: npm i -D playwright && npx playwright install chromium)
npm run test:widths    # من عرض 320 لـ 1440، عربي وإنجليزي، بدون تمرير جانبي
```

- كل اختبار بيشغّل نسخة محلية جديدة من قاعدة البيانات والسيرفر، وبيطفيهم بعدها.
- ما بيلمس حساب Cloudflare الحقيقي.
- لازم ما يكون في ملف `.dev.vars` أو `.env` بالمجلد.

## النشر

- كل رفع على `main` بينشر لحاله (`Cloudflare-guide.md`، الخطوة 4).
- أمر النشر بيحدّث جداول قاعدة البيانات أول، وبعدين بينشر الكود.
- تعديلات صاحب المحل والطلبات محفوظة بقاعدة البيانات، والنشر ما بيلمسها.
